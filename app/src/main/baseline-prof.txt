# Ahead-of-time compilation rules for this app's own code.
#
# Measured before writing it. On the release build, straight after an install, a
# scroll through the history was 4.99% janky with a 90th percentile of 17ms; after
# `cmd package compile -m speed-profile -f` - that is, once the JIT had seen the
# code - the same scroll was 0.98% janky at 9ms. The app is not slow. It is slow
# UNTIL IT HAS RUN, and every install and every app update puts the owner back at
# the start of that curve.
#
# The merged profile in the APK carried zero entries for `sa.masrouf` - the Compose
# and AndroidX libraries ship their own and the app shipped none - so every class
# here was interpreted, then JIT-compiled, on the first pass through it.
#
# These are written by hand rather than generated by a macrobenchmark, because the
# only device this app runs on is the owner's phone and `connectedAndroidTest`
# uninstalls the app it tests - which on that phone means twelve years of captured
# messages. A generated profile is more precise; a hand-written one over an app this
# small is coarse in a way that costs install time and nothing else.
#
# Flags: H = hot, S = startup, P = post-startup, L = class.

# --- startup: the process, the activity, the theme ------------------------
HSPLsa/masrouf/app/MainActivity;->**(**)**
HSPLsa/masrouf/app/MasroufApp;->**(**)**
Lsa/masrouf/app/MainActivity;
Lsa/masrouf/app/MasroufApp;

# --- every composable and everything they read ----------------------------
# The whole ui package: it is six thousand lines and all of it is either on the
# first frame or one scroll away.
HSPLsa/masrouf/app/ui/**->**(**)**
Lsa/masrouf/app/ui/**

# --- storage: Room mappers and the repository -----------------------------
# `toModel` runs once per row per query, and a month is several hundred rows.
HSPLsa/masrouf/app/data/**->**(**)**
Lsa/masrouf/app/data/**

# --- the pure core, which the rows call on every frame they compose --------
# MerchantNames.forMerchant on every history row, Money formatting on every
# figure, ArabicText folding underneath both, countsAsSpending on every total.
HSPLsa/masrouf/core/model/**->**(**)**
HSPLsa/masrouf/core/money/**->**(**)**
HSPLsa/masrouf/core/text/**->**(**)**
HSPLsa/masrouf/core/time/**->**(**)**
Lsa/masrouf/core/model/**
Lsa/masrouf/core/money/**
Lsa/masrouf/core/text/**
Lsa/masrouf/core/time/**

# --- capture, which runs at launch to read the tail of the inbox ----------
HSPLsa/masrouf/core/capture/**->**(**)**
HSPLsa/masrouf/app/capture/**->**(**)**
Lsa/masrouf/core/capture/**
Lsa/masrouf/app/capture/**
